# 简单连点器 (Simple Auto Clicker)

一个参考手机「自动点击器」的 Windows 鼠标连点工具：**纯 PowerShell 实现、零依赖、绿色单文件**，可打包为独立 exe 双击运行。

## 功能

- **多任务点**：录制多个点击位置，按顺序循环执行
- **每任务独立设置**：坐标 / 按键（左·右·中键）/ 类型（单击·双击·长按）/ 延时 / 随机偏移
- **随机延时**：延时支持区间写法，如 `1~3` = 每次随机 1~3 秒，更接近真人
- **随机偏移**：点击位置 ±N 像素随机抖动
- **轮数限制**：`0` = 无限循环，也可指定轮数，跑完自动停
- **轮间间隔**：一整轮任务完成后休息 N 秒再开下一轮
- **开始倒计时**：默认 3 秒，方便切到目标窗口；`0` 可关闭
- **全局热键**：F9 开始/停止 · F10 拾取位置 · F11 添加任务 · F12 保存预设（后台窗口也有效）
- **预设方案**：保存多套配置到 `presets` 文件夹，随时加载 / 删除
- **配置自动保存**：关闭时自动保存到 `config.json`，下次打开自动恢复

## 使用方法

### 方式一：直接运行 exe（推荐）

下载 Releases 里的 `AutoClicker.exe`，双击即可运行（Windows 7 SP1+ / 10 / 11，需 .NET Framework 4.5+）。

### 方式二：从源码运行

```powershell
# 双击「启动连点器.bat」即可（已配置免执行策略）
powershell -NoProfile -ExecutionPolicy Bypass -File "AutoClicker.ps1"
```

### 快速上手

1. 按 **F11** 添加任务 → 把鼠标移到目标位置 → 按 **F10** 拾取坐标
2. 设置延时（如 `5` 固定 5 秒，或 `1~3` 随机 1~3 秒）、类型、偏移
3. 按 **F9** 开始，再按 **F9** 停止（有倒计时，期间按 F9 取消）

### 热键一览

| 按键 | 功能 |
|---|---|
| F9 | 开始 / 停止（倒计时中 = 取消） |
| F10 | 拾取鼠标位置填入任务 |
| F11 | 添加任务 |
| F12 | 保存预设 |

```
├── AutoClicker.ps1      # 主程序源码（纯 PowerShell，中文注释）
├── AutoClicker.exe      # 打包好的独立应用
├── 启动连点器.bat        # 源码方式启动入口

```

## 自行打包 exe

```powershell
Install-Module ps2exe -Scope CurrentUser -Force
Import-Module ps2exe
Invoke-ps2exe -InputFile "AutoClicker.ps1" -OutputFile "AutoClicker.exe" -NoConsole -Title "简单连点器"
```

## 常见问题

**Q：鼠标能移动到位置，但点击没反应？**
A：这是 Windows 的**权限隔离（UIPI）**机制——如果目标程序是以管理员身份运行的（游戏、某些软件、安装程序），普通权限的工具发送的点击会被系统拦截，但移动鼠标不受限。
**解决办法**：右键 `AutoClicker.exe` → **以管理员身份运行**。普通窗口（记事本、浏览器、桌面等）不需要管理员。

**Q：双击没反应 / 闪退？**
A：需要 .NET Framework 4.5+（Win10/11 自带）。如被杀软误报，加白名单即可。
