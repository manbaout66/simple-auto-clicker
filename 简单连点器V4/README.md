# 简单连点器 V4（可视化版）

Windows 可视化自动连点器，与 v3.5（根目录版）完全独立、互不影响。

## 功能

- **可视化点击圈**：全屏透明覆盖层，每个任务显示一个带序号的圆圈（1、2、3…），位置即点击位置
- **圈圈交互**：拖动圆圈改坐标、右键圆圈删除该任务、运行时当前点击点高亮（黄晕绿心）
- **点击穿透**：运行时圆圈完全不挡鼠标，点击直达目标窗口内容
- **多任务点**：按顺序循环执行，每个任务独立 坐标/按键/类型/延时/偏移
- **点击类型**：单击 / 双击 / 长按(500ms)；按键：左/右/中键
- **随机延时**：支持区间写法，如 `1~3` = 每次随机 1~3 秒
- **随机偏移**：每任务可设 ±N 像素，点击位置随机抖动
- **执行控制**：轮数限制（0=无限）+ 轮间间隔 + 开始前倒计时
- **预设方案**：下拉框选中即加载全部任务/参数/圆圈，支持新建、保存（F12）、删除
- **全局热键**：F9 开始/停止 · F10 拾取位置 · F11 添加任务 · F12 保存当前预设
- **配置自动保存**：`%APPDATA%\SimpleAutoClickerV4\config.json`（含预设目录 presets\）

## 使用方法

1. 双击 `AutoClickerV4.exe`（或桌面快捷方式），无需安装
2. 按 F11 添加任务，屏幕上出现圆圈，拖动到目标位置（或 F10 拾取当前鼠标位置）
3. 按 F9 开始，倒计时后开始循环点击；再按 F9 停止

> 如果目标窗口是管理员权限运行的游戏/程序，请右键 exe →「以管理员身份运行」。

## 修复记录

- **v4.1 穿透修复**：运行时覆盖层启用系统级鼠标穿透（WS_EX_TRANSPARENT），修复点击被全屏透明层挡住、目标窗口无响应的问题
- DPI 适配：高分辨率/缩放 125% 下坐标精确对应物理像素
- 拖动圆圈：修复了主窗口模态导致圆圈收不到鼠标的问题

## 与 v3.5 的区别

| | v3.5（根目录） | V4（本目录） |
|---|---|---|
| 定位方式 | 表格手动填坐标 | 屏幕上拖圆圈，所见即所得 |
| 圈显示 | 无 | 带序号圆圈，运行中高亮 |
| 配置目录 | `%APPDATA%\SimpleAutoClicker\` | `%APPDATA%\SimpleAutoClickerV4\` |

## 技术说明

- PowerShell + WinForms + C#（SendInput 模拟点击、全局热键 GetAsyncKeyState）
- 打包工具：ps2exe（绿色单 exe）
- 源码 `AutoClickerV4.ps1` 可直接用 PowerShell 运行
